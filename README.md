## 📌 Project Overview

**CodeAlpha Image Gallery** is a responsive image gallery web application created as part of the **CodeAlpha one-month Front-End internship**. It organizes images into categories — Animals, Architecture, Nature, and People — with a clean grid layout and smooth browsing experience.

---

## ✨ Key Features

- 🗂️ **Category Pages** – Dedicated galleries for Animals, Architecture, Nature, and People
- 🖼️ **Grid Layout** – Clean, responsive image grid
- 🎨 **Consistent Styling** – Shared CSS for a unified look across pages
- ⚡ **Lightweight** – Pure HTML/CSS/JavaScript, no frameworks

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Page structure |
| **CSS3** | Styling and responsive grid layout |
| **JavaScript** | Interactivity and gallery behavior |

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/AmjadIbrahim1/CodeAlpha_Image_Gallery.git
   ```
2. Open `index.html` in any modern web browser.
3. Browse the categories — no setup required.
